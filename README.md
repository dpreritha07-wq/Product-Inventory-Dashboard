# Product Inventory & Analytics Dashboard

## About the Project
The Product Inventory & Analytics Dashboard is a JavaScript-based project that manages product information and generates inventory analytics. It demonstrates fundamental JavaScript concepts through interactive user input and data processing.

## Features
- Add products using user input.
- Validate product names and prices.
- Categorize products as Budget, Standard, or Premium.
- Display all products using `forEach()`.
- Calculate total inventory value using `reduce()`.
- Filter affordable products using `filter()`.
- Generate formatted product reports using `map()`.

## Technologies Used
- HTML5
- JavaScript

## Price Categories
- **Budget:** Price below $100
- **Standard:** Price from $100 to $500
- **Premium:** Price above $500

## How to Run
1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Enter the product name and price when prompted.
4. Open the browser Developer Tools and select Console to view the inventory analytics.

## Project Structure
- `index.html` — Web page and JavaScript connection.
- `script.js` — Product inventory logic and analytics.
